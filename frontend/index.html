Engine Architecture & Technology Stack

Deep Metric Learning

InceptionResnetV1 pretrained on VGGFace2 mapping face geometry into an L2-normalized 512-dimensional hypersphere.

MTCNN Cascaded Detection

Three-stage deep network (P-Net, R-Net, O-Net) for bounding box localization and facial feature alignment.

100-Class Softmax Head

Regularized multi-class classifier with rejection threshold T=0.45 for zero false-positives on non-players.

FastAPI Asynchronous Backend

Sub-millisecond static file delivery and threadpool inference processing without disk I/O bottlenecks.
